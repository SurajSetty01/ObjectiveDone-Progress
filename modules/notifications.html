T

What powers this module

Feature by feature — what each moving part actually runs on.

  • Notification centreReact Native SectionList grouped Today / Yesterday / date · hairline separators and unread marks per row · optimistic mark-read on tap + "Mark all read" header action — TanStack Query mutations that reconcile the list and unread-count caches together, with rollback on error
  • Home bell badgeGold unread count on the Home TopBar · fed by a TanStack Query unread key over the same store · refetches on every screen focus, so returning from the centre or an emit from any flow updates it without a manual refresh
  • Writing an entrynotify() helper — the one-line way for any feature (cards, contacts, account) to drop an entry, now inserted straight into the cloud table; fire-and-forget, it never throws into the calling flow
  • Where notifications liveLive on Supabase — the PostgreSQL notifications table from migration 0004, applied and verified on 27 July · supabaseNotificationRepository is the active data layer · row-level security is on, so an account can only ever read its own notes, proven with two signed-in test sessions
  • Staying signed inSupabase Auth session · the single-device sign-in lock is now active, so notes follow the one device a person is signed in on
