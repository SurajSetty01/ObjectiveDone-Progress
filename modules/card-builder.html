Module 04

Card Builder

In progress

This is where a card takes shape — your name and role, a photo and company logo, and every way to reach you, clubbed into tidy blocks you reorder with a drag of the finger. The builder refuses to save a card nobody can reply to, asks before unsaved work is lost, and every finished card — pictures included — lands in the live cloud the moment you tap Save. If something required is missing, the builder now says so at the top of the form rather than at the bottom, where the answer used to be a scroll away from the tap that failed.

T

What powers this module

Feature by feature — what each moving part actually runs on.

  • Form and fieldsShared FieldGroupsEditor — grouped +/− field boxes with drag-a-block reorder · phone-or-email rule enforced before any save · unsaved-changes guard on every exit path
  • Media stagingreact-native-image-picker for gallery picks · company-logo auto-detect reads the company site's own declared artwork first (apple-touch-icon, social preview image), then keyless icon services as fallback — no API token anywhere
  • Live previewThe preview modal renders the real card face from the live form input — what you see is exactly what saves
  • Card storageLIVE on the Supabase PostgreSQL cards table, verified against the real project on 27 July · owner-only access rules, so one account can never read another's cards
  • Profile prefillLIVE on the Supabase profiles table · the first card fills itself from your saved profile, and a first card with no profile behind it writes those details back
  • ImagesPhotos, logos and covers upload for real to Cloudflare R2 through short-lived signed links from the media-sign function, and survive a reinstall · Save waits for any picture still in flight, so a card can never point at a file that never arrived
  • Safe screen exitsrc/lib/leaveScreen.ts — dismisses the keyboard and waits two frames before the screen is torn down, curing a native crash in React Native's ScrollView focus search when a focused text field outlived its screen · applied to every form screen and verified on a real device
