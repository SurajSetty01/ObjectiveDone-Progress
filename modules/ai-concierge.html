Module 09

AI Concierge

In progress

A private concierge you chat with about the people you meet — every conversation keeps its own thread, with a drawer to search, pin and rename them. Your chats now live in your own cloud account rather than only on the phone, and the concierge's own service is switched on and set up to read your contacts. It is waiting on one thing: the key that connects the model itself. Until that arrives it says so plainly instead of guessing.

T

What powers this module

Feature by feature — what each moving part actually runs on.

  • Threaded chat experienceReact Native 0.80 (New Architecture) + TypeScript · thread drawer with search, pin, rename, delete · a new chat auto-titles itself from your first message — all built
  • Chat dataLIVE on Supabase PostgreSQL — ai_threads + ai_messages (migration 0004, applied and verified 2026-07-27) · the app now runs on supabaseAiRepository, so threads and messages persist to the account rather than the phone
  • Chat privacyOwner-only row-level security on both tables and, unlike cards or contacts, no administrator read path at all · isolation proven with two live signed-in sessions
  • Concierge serviceSupabase Edge Function ai-chat — DEPLOYED with its real implementation · verifies a genuine signed-in user (an anon key is rejected) and reads the caller's own contacts under their own credentials to ground the answer · Anthropic Claude Haiku 4.5, replaying the last 20 turns
  • Model keyANTHROPIC_API_KEY is not set yet, so the function answers 503 and the app persists an honest "the model isn't connected yet" reply · setting the secret upgrades replies in place — no app change, no rebuild
  • Crash safety in the composerA focused text field surviving a screen closing tripped an unguarded null inside React Native's scroll-view focus search and crashed the app natively · found, fixed and applied across every screen carrying a text field, this composer included · verified on a real device
  • DictationuseVoiceInput keeps its real interface — the mic sits in the composer and explains itself on tap today (@react-native-voice/voice removed in M2.1 over an AndroidX manifest clash)
