T

What powers this module

Feature by feature — what each moving part actually runs on.

  • Pedestal carouselReanimated 3 springs + react-native-gesture-handler pan — custom fling-and-settle physics, one engine shared with the My Cards wallet
  • The three designsLocked card geometry rendered from 1000×1400 pre-generated plates · Obsidian / Gold / Platinum material variants · sample persona faces, display only
  • HandoffReact Navigation params carry the chosen theme (plus onboarding vs member origin) straight into the Card Builder
  • Where the card is savedThe live Supabase PostgreSQL cards table — every row is owner-scoped, so a member can only ever read and write their own cards. Proven with two separate signed-in accounts
  • The mandatory first-card gateReact Navigation's root stack counts the signed-in member's cards in that same live table and swaps stacks — an empty wallet forces Select Design → Card Builder with no way back
  • Save reliabilityThe native crash that could hit a card save — a still-focused text field surviving the screen teardown — is fixed, and the same guard is applied to every form screen
